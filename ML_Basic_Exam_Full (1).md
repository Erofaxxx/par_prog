# 1. Машинное обучение (ML): определение и методология

## 1a. На каких дисциплинах основано ML

**Машинное обучение** находится на пересечении нескольких фундаментальных дисциплин:

- **Математическая статистика** — теория вероятностей, статистическое оценивание, проверка гипотез, байесовский вывод. Это основа для понимания данных, неопределённости и построения вероятностных моделей.

- **Линейная алгебра** — матричные операции, собственные значения, SVD-разложение. Данные представляются в виде матриц, а многие алгоритмы сводятся к матричным вычислениям.

- **Оптимизация** — методы поиска минимума/максимума функций (градиентный спуск, выпуклая оптимизация). Обучение моделей — это задача оптимизации функции потерь.

- **Информатика и алгоритмы** — структуры данных, сложность алгоритмов, эффективные вычисления.

- **Теория информации** — энтропия, взаимная информация, кодирование. Используется в деревьях решений, кросс-энтропии.

## 1b. Отличие классического программирования от ML

**Классическое программирование:** программист явно задаёт правила:
```
(Данные + Правила) → Результат
```
Например, для определения спама пишутся конкретные правила: «если содержит слово X, то спам».

**Машинное обучение:** система сама извлекает правила из данных:
```
(Данные + Результаты) → Правила (модель)
```
Модель обучается на примерах писем с метками «спам/не спам» и сама находит закономерности.

**Ключевое отличие:** в ML мы не программируем решение напрямую, а создаём систему, которая учится находить решение на основе данных.

## 1c. Базовые термины ML

- **Объект (sample, instance)** — единица данных, описываемая набором признаков (один пациент, одно изображение).

- **Признак (feature)** — измеримая характеристика объекта (возраст, интенсивность пикселя).

- **Целевая переменная (target, label)** — то, что мы хотим предсказать. В регрессии — число, в классификации — класс.

- **Датасет (dataset)** — набор объектов. Матрица X размера (n_samples × n_features) и вектор y целевых значений.

- **Модель (model)** — алгоритм/функция, которая делает предсказания на основе признаков.

- **Обучение (training)** — процесс настройки параметров модели для минимизации ошибки.

- **Предсказание (inference)** — применение обученной модели к новым данным.

# 4. Разведочный анализ данных (EDA)

## 4a. Важность EDA для моделирования

EDA (Exploratory Data Analysis) — критический этап перед построением моделей:

- **Понять структуру данных:** типы признаков, размерность, форматы
- **Обнаружить проблемы:** пропущенные значения, выбросы, дубликаты, ошибки
- **Выявить закономерности:** корреляции, распределения, кластеры
- **Сформировать гипотезы:** какие признаки важны, какие преобразования нужны

**Пример:** при анализе данных о ценах на жильё EDA может выявить сильную корреляцию цены с площадью, наличие выбросов, пропуски в данных о годе постройки.

1. **Загрузка и первичный осмотр:** `df.head()`, `df.info()`, `df.shape`, `df.dtypes`
2. **Статистические сводки:** `df.describe()` — среднее, медиана, квартили
3. **Анализ пропусков:** `df.isnull().sum()`
4. **Визуализация распределений:** гистограммы, boxplot для выбросов
5. **Анализ корреляций:** корреляционная матрица (heatmap), scatter plots
6. **Анализ категориальных признаков:** `value_counts()`
7. **Анализ целевой переменной:** баланс классов, распределение

# 5. Метод максимального правдоподобия (MLE)

## 5a. Определение правдоподобия (Likelihood)

**Правдоподобие (Likelihood)** — функция параметров модели θ, показывающая насколько вероятно наблюдать имеющиеся данные:

$$L(\theta) = P(Data | \theta)$$

**Важно:** Likelihood — функция от параметров θ (данные фиксированы), а не вероятность параметров.

MLE ищет θ*, которые максимизируют правдоподобие: θ* = argmax L(θ)

**Пример:** подбрасываем монету 10 раз, выпало 7 орлов. L(p) = C(10,7) × p⁷ × (1-p)³. MLE даст p* = 0.7.

## 5b. Свойство i.i.d. и его последствия

**i.i.d. (independent and identically distributed)** — независимые одинаково распределённые случайные величины.

- **Independent (независимость):** наблюдение одного объекта не влияет на другие
- **Identically distributed:** все объекты порождены одним процессом

**Главное следствие для MLE:** совместная вероятность равна произведению:

$$L(\theta) = P(x_1, x_2, ..., x_n | \theta) = \prod_{i=1}^{n} P(x_i | \theta)$$

## 5c. Формула отрицательного логарифма правдоподобия (NLL)

Вместо максимизации L(θ) минимизируем отрицательный логарифм:

$$NLL(\theta) = -\log L(\theta) = -\sum_{i=1}^{n} \log P(x_i | \theta)$$

**Почему логарифм:**
1. Произведение превращается в сумму (удобнее дифференцировать)
2. Избегаем численного underflow (произведение малых чисел → 0)
3. Логарифм монотонен — argmax сохраняется

**Связь с ML:** cross-entropy, logistic loss — это NLL для соответствующих распределений.

# 6. Таксономия задач ML

## 6a. Supervised и Unsupervised learning

**Обучение с учителем (Supervised Learning):** есть размеченные данные (X, y). Модель учится предсказывать y по X.
- **Классификация:** y — дискретные метки (спам/не спам)
- **Регрессия:** y — непрерывные значения (цена)

**Обучение без учителя (Unsupervised Learning):** только X, нет меток. Модель ищет скрытую структуру.
- **Кластеризация:** группировка похожих объектов
- **Снижение размерности:** сжатие данных (PCA)

## 6b. Другие категории задач ML

- **Semi-supervised learning:** часть данных размечена, часть нет
- **Self-supervised learning:** модель создаёт псевдо-метки из данных (BERT)
- **Reinforcement Learning:** агент обучается через взаимодействие со средой
- **Transfer Learning:** перенос знаний с одной задачи на другую

## 6c. Практические примеры

**Supervised — Классификация:**
1. Фильтрация спама в почте
2. Диагностика заболеваний по симптомам
3. Распознавание рукописных цифр

**Supervised — Регрессия:**
1. Прогнозирование цены недвижимости
2. Предсказание спроса на товары
3. Оценка кредитного рейтинга

**Unsupervised:**
1. Сегментация клиентов по поведению
2. Детекция аномалий (мошенничество)
3. Визуализация высокоразмерных данных (t-SNE)

## 6d. Практическая постановка задачи

- **X** — матрица признаков (n × d): n объектов, d признаков
- **y** — вектор целевых значений (n)
- **f: X → Y** — модель, отображающая признаки в предсказания
- **L(y, ŷ)** — функция потерь (loss)
- **Задача:** найти параметры θ, минимизирующие L на обучающих данных

# 7. Наивный байесовский классификатор

## 7a. Теорема Байеса

$$P(y | x) = \frac{P(x | y) \cdot P(y)}{P(x)}$$

- **P(y)** — априорная вероятность класса (до наблюдения признаков)
- **P(x | y)** — правдоподобие (вероятность признаков при классе y)
- **P(y | x)** — апостериорная вероятность класса
- **P(x)** — evidence (нормализующая константа)

## 7b. Основные предположения (почему «наивный»)

**Наивное предположение:** признаки условно независимы при фиксированном классе:

$$P(x_1, x_2, ..., x_d | y) = \prod_{j=1}^{d} P(x_j | y)$$

Это «наивно», потому что признаки часто коррелируют. Но классификатор работает, потому что важен порядок классов по вероятности, а не точные значения.

**Решающее правило:** ŷ = argmax_y P(y) ∏ P(xⱼ | y)

## 7c. Случай непрерывных признаков

**Gaussian Naive Bayes:** предполагается нормальное распределение:

$$P(x_j | y) = \mathcal{N}(x_j | \mu_{jy}, \sigma^2_{jy})$$

где μⱼy и σ²ⱼy — среднее и дисперсия признака j для класса y.

**Другие варианты:** Multinomial NB (для счётчиков), Bernoulli NB (для бинарных признаков).

# 8. Библиотека Sklearn

## 8a. Основные классы и использование

**Estimators (модели)** — унифицированный интерфейс:
- `fit(X, y)` — обучение модели
- `predict(X)` — предсказание
- `predict_proba(X)` — вероятности классов
- `score(X, y)` — оценка качества

**Transformers (преобразователи):**
- `fit(X)` — обучение преобразования
- `transform(X)` — применение
- `fit_transform(X)` — обучение и применение за раз

**Примеры классов:**
- LinearRegression, LogisticRegression
- DecisionTreeClassifier/Regressor
- StandardScaler, MinMaxScaler
- train_test_split, cross_val_score

## 8b. Важность пайплайнов (Pipeline)

**Pipeline** объединяет преобразования и модель в единый объект.

**Преимущества:**
1. Избегание data leakage: преобразования обучаются только на train
2. Удобство: один вызов fit/predict
3. Воспроизводимость: легко сохранить весь пайплайн

```python
from sklearn.pipeline import Pipeline
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('clf', LogisticRegression())
])
pipe.fit(X_train, y_train)
pipe.predict(X_test)
```

# 9. Регрессионная модель

## 9a. Предположения регрессионной модели

1. **Линейность:** y = Xw + ε
2. **Независимость ошибок:** εᵢ независимы друг от друга
3. **Гомоскедастичность:** Var(εᵢ) = σ² для всех i
4. **Нормальность ошибок:** εᵢ ~ N(0, σ²) — для статистических тестов
5. **Отсутствие мультиколлинеарности:** признаки не линейно зависимы

# 10. Линейная регрессия

## 10a. Обоснование MSE loss

**MSE (Mean Squared Error):**
$$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

**Почему квадрат:**
1. Дифференцируемость везде
2. Штрафует большие ошибки сильнее
3. Приводит к аналитическому решению

**Вероятностное обоснование:** если ε ~ N(0, σ²), то MLE эквивалентен минимизации MSE.

## 10b. Аналитическое решение (матричная форма)

Задача: минимизировать L(w) = ||Xw - y||²

**Решение (Normal Equation):**
$$w^* = (X^T X)^{-1} X^T y$$

**Вывод:**
```
∇L = 2Xᵀ(Xw - y) = 0
XᵀXw = Xᵀy
w = (XᵀX)⁻¹Xᵀy
```

## 10c. Теорема Гаусса-Маркова. BLUE

**Теорема:** при выполнении предположений регрессии OLS-оценка является **BLUE**.

**BLUE = Best Linear Unbiased Estimator:**
- **Best:** минимальная дисперсия среди линейных несмещённых оценок
- **Linear:** оценка линейна по y
- **Unbiased:** E[ŵ] = w (несмещённая)

# 11. Градиентный спуск для линейной регрессии

## 11a. Почему матричное решение не всегда используется

**Проблемы w* = (XᵀX)⁻¹Xᵀy:**
1. **Вычислительная сложность:** обращение матрицы O(d³). При d > 10000 очень медленно.
2. **Память:** нужно хранить XᵀX размера d×d
3. **Численная нестабильность:** при мультиколлинеарности обращение неточно
4. **Масштабируемость:** градиентный спуск работает с батчами

## 11b. Стохастический градиентный спуск (SGD)

**Обычный GD:** wₜ₊₁ = wₜ - η∇L(wₜ), градиент по всем данным.

**SGD:** градиент по одному объекту или мини-батчу:
$$w_{t+1} = w_t - \eta \nabla L(w_t; x_i, y_i)$$

**Преимущества SGD:**
1. Быстрее: не нужно проходить все данные для одного шага
2. Работает с потоковыми данными (online learning)
3. Шум в градиенте помогает выбираться из локальных минимумов
4. Масштабируется на огромные датасеты

# 12. Регуляризация в линейных моделях

## 12a. Мотивация для регуляризации

**Проблемы без регуляризации:**
1. Переобучение: модель запоминает шум
2. Большие веса при мультиколлинеарности
3. Неустойчивость решения

**Идея:** добавить штраф за сложность модели (большие веса).

## 12b. Ridge регрессия (L2)

$$L(w) = ||Xw - y||^2 + \lambda ||w||^2$$

**Аналитическое решение:**
$$w^* = (X^T X + \lambda I)^{-1} X^T y$$

**Свойства:** λI делает матрицу обратимой; веса уменьшаются, но не обнуляются.

## 12c. Lasso регуляризация (L1)

$$L(w) = ||Xw - y||^2 + \lambda \sum_j |w_j|$$

**Ключевое свойство:** приводит к разреженным решениям — часть весов = 0.

**Применение:** отбор признаков (feature selection).

## 12e. Elastic Net

$$L(w) = ||Xw - y||^2 + \lambda_1 \sum_j |w_j| + \lambda_2 ||w||^2$$

Комбинация L1 и L2: разреженность L1 + стабильность L2.

## 12f. Свойства регуляризаций

**L2 (Ridge):** уменьшает все веса пропорционально; устойчив к мультиколлинеарности.

**L1 (Lasso):** даёт разреженное решение; неустойчив при коррелированных признаках.

**Геометрически:** L1 — ромб, L2 — шар. Пересечение с изолиниями loss чаще в вершинах ромба для L1.

# 13. Метрики регрессии

- **MSE:** (1/n)∑(yᵢ - ŷᵢ)². Штрафует большие ошибки. Единица — квадрат исходной.
- **RMSE:** √MSE. Интерпретируется в исходных единицах.
- **MAE:** (1/n)∑|yᵢ - ŷᵢ|. Менее чувствителен к выбросам.
- **MAPE:** (100%/n)∑|yᵢ - ŷᵢ|/|yᵢ|. Относительная ошибка. Не определён при y=0.
- **SMAPE:** Симметричная версия MAPE.
- **R²:** 1 - SS_res/SS_tot. Доля объяснённой дисперсии. R²=1 идеально, R²=0 как среднее.

**Когда использовать:** MSE/RMSE — стандарт; MAE — при выбросах; MAPE — относительная ошибка; R² — интерпретация.

# 15. Валидация и оценка моделей

## 15a. Underfitting и Overfitting

**Underfitting (недообучение):** модель слишком простая.
- Признак: высокая ошибка и на train, и на test
- Решение: усложнить модель, добавить признаки

**Overfitting (переобучение):** модель слишком сложная, запоминает шум.
- Признак: низкая ошибка на train, высокая на test
- Решение: регуляризация, больше данных, упрощение

## 15b. Методы разбиения данных

1. **Hold-out:** простое разбиение train/test (80/20). Быстро, но зависит от разбиения.
2. **K-Fold Cross-Validation:** данные делятся на K частей; K обучений.
3. **Stratified K-Fold:** сохраняет пропорции классов в каждом fold.
4. **Time Series Split:** для временных рядов — train всегда до test.

## 15c. Этапы построения модели

- **Train set:** для обучения параметров
- **Validation set:** для подбора гиперпараметров
- **Test set:** для финальной оценки (один раз!)
- **Cross-validation:** заменяет validation при малых данных

## 15d. Утечки данных (Data Leaks)

**Data Leakage:** информация из test просачивается в train.

**Примеры:**
1. Нормализация на всех данных до split
2. Признаки, вычисленные с использованием target
3. Дублирование данных

**Как избежать:** Pipeline, все преобразования fit только на train.

# 16. Линейная классификация

## 16a-b. Постановка задачи и типы меток

**Задача:** найти f: X → Y, минимизирующую ошибку классификации.

**Типы меток:**
- Бинарная: y ∈ {0, 1} или {-1, +1}
- Многоклассовая: y ∈ {1, ..., K}
- Multi-label: объект может принадлежать нескольким классам

## 16c. Линейный классификатор

$$\hat{y} = sign(w^T x + b)$$

**Геометрически:** w — нормаль к гиперплоскости, b — смещение.

## 16d. Определение отступа (Margin)

$$M(x, y) = y \cdot (w^T x + b)$$

**Свойство:** M > 0 — правильная классификация, M < 0 — ошибка.

## 16e-f. Выбор весов и разные loss

Нельзя минимизировать 0-1 loss (недифференцируема, NP-hard).

**Суррогатные loss:**
- Hinge loss (SVM): max(0, 1 - M)
- Logistic loss: log(1 + exp(-M))
- Exponential loss (AdaBoost): exp(-M)

# 17. Логистическая регрессия

## 17a. Основное предположение

Log-odds линейно зависит от признаков:
$$\log\frac{P(y=1|x)}{P(y=0|x)} = w^T x + b$$

## 17b. Сигмоида

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**Свойства:**
- Выход в (0, 1) — интерпретируется как вероятность
- σ(0) = 0.5
- σ(-z) = 1 - σ(z)
- σ'(z) = σ(z)(1 - σ(z))

## 17c. Логистическая функция потерь

**Log loss (Binary Cross-Entropy):**
$$L = -\sum_i [y_i \log(\hat{p}_i) + (1-y_i) \log(1-\hat{p}_i)]$$

где p̂ᵢ = σ(wᵀxᵢ + b).

**Связь с MLE:** это NLL для бернуллиевского распределения.

## 17d. Калибровка вероятностей

**Калибровка:** если модель предсказывает P=0.7, то ~70% таких объектов должны быть положительными.

Логистическая регрессия даёт хорошо откалиброванные вероятности.

# 18. Стратегии многоклассовой классификации

## 18a. One-vs-One и One-vs-All

**One-vs-All (OvA):**
- K бинарных классификаторов
- i-й: класс i vs все остальные
- Предсказание: класс с максимальным score

**One-vs-One (OvO):**
- K(K-1)/2 классификаторов (для каждой пары)
- Предсказание: голосование

**Сравнение:** OvA — меньше моделей; OvO — каждая на меньших данных.

# 19. Метрики классификации

## 19a. Метрика vs Loss

**Метрика:** оценка качества модели.
- Не обязательно дифференцируема
- Интерпретируема
- Вычисляется на validation/test

## 19b. Confusion Matrix

- **TP** — верно предсказанные положительные
- **TN** — верно предсказанные отрицательные
- **FP** — ошибка I рода (ложная тревога)
- **FN** — ошибка II рода (пропуск)

## 19c. Accuracy, Precision, Recall, F1

- **Accuracy:** (TP + TN) / (TP + TN + FP + FN). Плоха при дисбалансе.
- **Precision:** TP / (TP + FP) — «точность»
- **Recall:** TP / (TP + FN) — «полнота»
- **F1:** 2 × Precision × Recall / (Precision + Recall)

## 19d. ROC AUC

**ROC-кривая:** TPR vs FPR при разных порогах.

**ROC-AUC:** площадь под ROC. AUC=0.5 — случайный, AUC=1 — идеальный.

**Интерпретация:** вероятность, что положительный объект получит более высокий score, чем отрицательный.

**PR AUC:** полезнее при сильном дисбалансе.

## 19e. Многоклассовые расширения

- **Micro-averaging:** общие TP, FP, FN, затем метрика
- **Macro-averaging:** метрика для каждого класса, затем среднее

# 21. Метод опорных векторов (SVM)

## 21a. Геометрическая интерпретация

**Идея:** найти гиперплоскость, максимизирующую отступ (margin) до ближайших объектов.

**Опорные векторы:** объекты на границе margin — определяют положение гиперплоскости.

## 21d. Hinge loss

$$L = \max(0, 1 - y(w^T x + b))$$

Штрафует объекты с margin < 1 линейно.

## 21e. Kernel trick

**Идея:** перейти в пространство более высокой размерности, где данные линейно разделимы.

**Kernel:** K(x, x') = φ(x)ᵀφ(x') — вычисляем скалярное произведение без явного вычисления φ.

**Примеры ядер:**
- Линейное: K(x, x') = xᵀx'
- Полиномиальное: K(x, x') = (xᵀx' + c)^d
- RBF (Gaussian): K(x, x') = exp(-γ||x - x'||²)

# 22. Метод главных компонент (PCA)

## 22a. Связь с SVD

PCA находит направления максимальной дисперсии данных.

**Связь с SVD:** если X — центрированные данные, X = UΣVᵀ, то главные компоненты — столбцы V.

## 22c. Две альтернативные формулировки

1. **Максимизация дисперсии:** найти направление w, максимизирующее Var(Xw)
2. **Минимизация ошибки восстановления:** найти проекцию, минимизирующую ||X - X_reconstructed||²

## 22d. Предобработка для PCA

**Обязательно:** центрирование данных (вычитание среднего).

**Рекомендуется:** стандартизация (деление на std), если признаки в разных масштабах.

# 24. kNN индексы

## 24c. HNSW алгоритм

**Hierarchical Navigable Small World:**

**Построение графа:**
- Многоуровневая структура
- Верхние уровни — редкие связи (быстрая навигация)
- Нижние уровни — плотные связи (точный поиск)

**Поиск:**
- Начинаем с верхнего уровня
- Жадно спускаемся к ближайшему соседу

# 26. Деревья решений

## 26a. Жадные алгоритмы

**Жадный алгоритм:** на каждом шаге выбирает локально оптимальное решение без оглядки на глобальную картину.

Построение дерева — жадный алгоритм: на каждом узле выбираем лучшее разбиение.

## 26b. Процедура построения

1. Начинаем с корня со всеми данными
2. Для каждого признака и порога вычисляем критерий качества разбиения
3. Выбираем лучшее разбиение
4. Рекурсивно строим поддеревья
5. Останавливаемся по критерию (глубина, минимум объектов, чистота)

## 26c. Информационные критерии

**Энтропия:**
$$H(p) = -\sum_k p_k \log_2 p_k$$

**Gini impurity:**
$$Gini(p) = 1 - \sum_k p_k^2$$

**Information Gain:**
$$IG = H(parent) - \sum_{child} \frac{n_{child}}{n_{parent}} H(child)$$

## 26d. Ответ в листе

**Классификация:** большинство голосов или вероятности классов.

**Регрессия:** среднее значений в листе.

## 26e. Обработка пропущенных значений

- Surrogate splits (альтернативные разбиения)
- Отдельная ветка для пропусков
- Замена медианой/модой

## 26f. Бинаризация

Деревья работают с бинарными разбиениями:
- Числовые признаки: x < threshold
- Категориальные: множество значений

## 26h. Гиперпараметры

1. **max_depth** — максимальная глубина
2. **min_samples_split** — минимум объектов для разбиения
3. **min_samples_leaf** — минимум объектов в листе
4. **max_features** — число признаков для выбора разбиения
5. **criterion** — entropy или gini

# 27. Bias-Variance-Noise декомпозиция

## 27a. Источники ошибки

$$E[(y - \hat{f}(x))^2] = Bias^2 + Variance + Noise$$

- **Bias²** — систематическая ошибка модели (насколько в среднем предсказание отличается от истинного)
- **Variance** — разброс предсказаний на разных обучающих выборках
- **Noise** — неустранимая ошибка в данных

## 27c. Bias-Variance tradeoff

- **Простые модели:** высокий bias, низкая variance (underfitting)
- **Сложные модели:** низкий bias, высокая variance (overfitting)

**Анализ моделей:**
- Линейная регрессия: высокий bias, низкая variance
- Глубокие деревья: низкий bias, высокая variance
- kNN с малым k: низкий bias, высокая variance

## 27e. Double descent

Феномен: при увеличении сложности модели ошибка сначала растёт (overfitting), затем снова падает при очень большой сложности (современные нейросети).

# 28. Бэггинг

## 28a. Мотивация (Bias-Variance)

**Идея:** уменьшить variance путём усреднения нескольких моделей.

Variance среднего N независимых предсказаний в N раз меньше variance одного.

## 28b. Bootstrap

**Bootstrap:** выборка с возвращением размера n из исходных n объектов.

Примерно 63.2% уникальных объектов в каждой bootstrap выборке.

## 28c. Random Subspace Method

На каждом дереве/разбиении используем случайное подмножество признаков.

## 28d. Random Forest

**Random Forest = Bagging + Random Subspace для деревьев решений**

1. Создаём N bootstrap выборок
2. На каждой обучаем дерево, на каждом разбиении выбирая из случайного подмножества признаков
3. Усредняем предсказания (или голосование)

**Отличие от просто Bagging:** дополнительная рандомизация на уровне признаков.

# 30. Градиентный бустинг

## 30a. Процедура построения для MSE

1. Инициализация: f₀(x) = ȳ (среднее)
2. Для t = 1, ..., T:
   - Вычисляем остатки: rᵢ = yᵢ - fₜ₋₁(xᵢ)
   - Обучаем базовую модель hₜ на (X, r)
   - Обновляем: fₜ = fₜ₋₁ + η·hₜ

## 30b. Бустинг как градиентный спуск

Для MSE: остатки = -градиент loss по предсказаниям.

В общем случае: следующая модель обучается на антиградиент функции потерь.

## 30c. Выбор базовой модели

Обычно — **неглубокие деревья** (stumps или глубина 3-6).

Почему деревья: адаптивны, работают с разными типами признаков, быстро обучаются.

## 30d. Параллелизм

- Построение одного дерева параллелится по признакам
- Деревья строятся последовательно (нельзя параллелить по деревьям)

# 36. Линейный слой

## 36a. Названия

Fully Connected, Dense, Linear, Affine layer.

## 36b. Формула

$$y = Wx + b$$

где W — матрица весов, b — bias.

## 36c. Гиперпараметры и число параметров

**Гиперпараметры:** input_dim, output_dim

**Число параметров:** input_dim × output_dim + output_dim (веса + bias)

Пример: 10 → 3: 10 × 3 + 3 = 33 параметра

## 36d. Инициализация

- **Xavier/Glorot:** Var(w) = 2 / (fan_in + fan_out)
- **He:** Var(w) = 2 / fan_in (для ReLU)
- **Нули/единицы:** плохо (симметрия, градиенты)

## 36e. Теорема об универсальной аппроксимации

Нейросеть с одним скрытым слоем и нелинейной активацией может аппроксимировать любую непрерывную функцию на компакте с произвольной точностью (при достаточной ширине слоя).

# 37. Функции активации

## 37a. Примеры (минимум 4)

1. **Sigmoid:** σ(x) = 1/(1+e⁻ˣ). Выход (0,1). Проблема vanishing gradients.
2. **Tanh:** tanh(x) = (eˣ - e⁻ˣ)/(eˣ + e⁻ˣ). Выход (-1,1). Zero-centered.
3. **ReLU:** max(0, x). Простая, быстрая. Проблема "dying ReLU".
4. **Leaky ReLU:** max(αx, x), α≈0.01. Решает dying ReLU.
5. **GELU:** x·Φ(x). Используется в трансформерах.
6. **Swish:** x·σ(x). Гладкая альтернатива ReLU.

## 37b. Сравнительный анализ

- **Vanishing gradients:** sigmoid, tanh страдают; ReLU нет
- **Dying neurons:** ReLU страдает; Leaky ReLU, ELU нет
- **Вычислительная эффективность:** ReLU самая быстрая
- **Smooth:** GELU, Swish гладкие; ReLU нет

# 38. Backpropagation

## 38a. Chain Rule

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial w}$$

**Алгоритм:**
1. Forward pass: вычисляем выходы всех слоёв
2. Backward pass: вычисляем градиенты от выхода к входу по chain rule
3. Обновляем веса: w := w - η·∇L

# 39. Многоклассовая классификация

## 39a. Softmax

$$softmax(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

**Свойства:**
- Выходы в (0,1), сумма = 1 (вероятности)
- Инвариантность к сдвигу: softmax(z) = softmax(z - c)
- **Численная стабильность:** вычитаем max(z) перед exp

## 39b. Cross-Entropy Loss

**Information content:** I(x) = -log P(x)

**Entropy:** H(p) = E[-log p] = -∑ pᵢ log pᵢ

**Cross-entropy:**
$$H(p, q) = -\sum_i p_i \log q_i$$

**Для классификации:** p — one-hot истинный класс, q — предсказанные вероятности.

$$L = -\log q_{true\_class}$$

**Perplexity:** exp(H) — среднее число вариантов.

**KL-divergence:** D_KL(p||q) = H(p, q) - H(p) ≥ 0

# 42. Рекуррентные нейронные сети (RNN)

## 42a. Последовательные данные

**Токен:** элементарная единица последовательности (слово, символ, кадр).

**Примеры:** текст, временные ряды, аудио, видео.

## 42b. Vanilla RNN

$$h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b)$$
$$y_t = W_{hy} h_t$$

**Размеры:**
- x_t: (input_size,)
- h_t: (hidden_size,)
- W_xh: (hidden_size, input_size)
- W_hh: (hidden_size, hidden_size)

## 42c. Token encoding

- One-hot encoding
- Embedding (обучаемое плотное представление)
- Pretrained embeddings (Word2Vec, GloVe)

## 42d. Постановки задач для RNN

- **Many-to-one:** классификация текста
- **One-to-many:** генерация текста
- **Many-to-many:** машинный перевод, NER

## 42e-f. Backpropagation через RNN

**BPTT (Backpropagation Through Time):** разворачиваем RNN во времени, применяем стандартный backprop.

**Функции активации:** tanh (ограниченные градиенты), иногда ReLU.

## 42g. Гиперпараметры и параметры

**Гиперпараметры:** hidden_size, num_layers, dropout

**Число параметров:** input_size × hidden_size + hidden_size × hidden_size + hidden_size × output_size + biases

## 42h. Проблемы градиентов

- **Vanishing gradients:** градиенты экспоненциально уменьшаются при длинных последовательностях
- **Exploding gradients:** градиенты экспоненциально растут

**Решения:**
- Gradient clipping (для exploding)
- LSTM, GRU (для vanishing)
- Skip connections

# 43. LSTM

## 43a. Мотивация

Vanilla RNN не может хранить долгосрочные зависимости (vanishing gradients).

**Почему LSTM решает:** отдельная cell state с аддитивными обновлениями позволяет градиентам течь без умножения.

## 43b. Memory и Gates

**Cell state (C_t):** долгосрочная память.

**Gates:**
- **Forget gate:** какую информацию забыть из C
- **Input gate:** какую новую информацию добавить
- **Output gate:** что вывести в hidden state

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$$
$$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$$
$$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)$$
$$\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C)$$
$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$
$$h_t = o_t \odot \tanh(C_t)$$

## 43c. Число параметров

4 × (input_size × hidden_size + hidden_size × hidden_size + hidden_size)

≈ 4 × hidden_size × (input_size + hidden_size)

## 43d. GRU (Gated Recurrent Unit)

Упрощённая версия LSTM:
- 2 гейта вместо 3 (reset, update)
- Нет отдельной cell state
- Меньше параметров

# 45. Операция свёртки

## 45a. Свёртка функций и матриц

**Дискретная 2D свёртка:**
$$(I * K)_{i,j} = \sum_m \sum_n I_{i+m, j+n} \cdot K_{m,n}$$

## 45b. Локальные рецептивные поля

Каждый нейрон «видит» только локальную область входа (receptive field).

## 45c. Выбор размера ядра

- **3×3:** наиболее распространённый, два 3×3 эквивалентны одному 5×5
- **1×1:** изменение числа каналов без пространственного смешивания
- **Нечётные размеры:** симметричный padding

## 45d. 1×1 свёртки

- Изменяют число каналов
- Эквивалентны FC слою для каждого пикселя
- Меньше параметров чем FC

## 45e. Гиперпараметры и параметры

**Гиперпараметры:** kernel_size, stride, padding, in_channels, out_channels

**Число параметров:** kernel_size² × in_channels × out_channels + out_channels

## 45f. Вычисление размера выхода

$$out = \lfloor \frac{in + 2 \cdot padding - kernel\_size}{stride} \rfloor + 1$$

## 45i. Потребление памяти

CNN потребляет больше памяти на активациях (нужно хранить для backprop), но меньше параметров чем FC.

# 50. Механизм внимания (Attention)

## 50a. RNN seq2seq модель

**Encoder-Decoder:**
- Encoder: читает входную последовательность, выдаёт context vector
- Decoder: генерирует выходную последовательность из context

## 50b. Мотивация для внимания

Проблема: весь вход сжимается в один фиксированный вектор (bottleneck).

Решение: на каждом шаге декодера смотреть на все состояния энкодера.

## 50c. Cross-attention в seq2seq

На каждом шаге декодера:
1. Query: текущее состояние декодера
2. Keys/Values: все состояния энкодера
3. Attention weights: softmax(QKᵀ/√d)
4. Context: взвешенная сумма Values

## 50d. Self-attention

Attention внутри одной последовательности: Query, Key, Value — все из одного входа.

## 50e. Другие виды внимания

- Additive attention (Bahdanau)
- Multiplicative attention (Luong)
- Multi-head attention
- Local attention

# 52. Геометрическое машинное обучение

## 52a. Проклятие размерности

При увеличении размерности:
- Объём растёт экспоненциально
- Точки становятся «далеко» друг от друга
- Нужно экспоненциально больше данных

## 52b. Manifold assumption

**Гипотеза многообразия:** данные высокой размерности лежат вблизи многообразия низкой размерности.

**Latent space:** пространство низкой размерности, где данные «живут».

**Intrinsic dimension:** истинная размерность многообразия данных.

# 53. Снижение размерности

## 53a. IsoMap

Нелинейное снижение размерности, сохраняющее геодезические расстояния.

1. Строим граф k-ближайших соседей
2. Вычисляем кратчайшие пути (геодезические расстояния)
3. Применяем MDS (Multidimensional Scaling)

## 53b. t-SNE

**t-distributed Stochastic Neighbor Embedding:**
- В высоком измерении: вероятности соседства через Gaussian
- В низком: через t-распределение (тяжёлые хвосты)
- Минимизируем KL-divergence

Хорош для визуализации, плохо сохраняет глобальную структуру.

## 53c. UMAP

**Uniform Manifold Approximation and Projection:**
- Быстрее t-SNE
- Лучше сохраняет глобальную структуру
- Основан на теории топологии

# 55. Задача ранжирования

## 55a. Постановка задачи

**Цель:** упорядочить объекты по релевантности для запроса.

**Отличие от регрессии:** важен порядок, не точные значения.

**Отличие от классификации:** градации релевантности, не бинарные метки.

## 55b. Офлайн метрики

**mAP (mean Average Precision):**
- AP для каждого запроса: площадь под precision-recall кривой
- mAP: среднее AP по всем запросам

**NDCG (Normalized Discounted Cumulative Gain):**
$$DCG_k = \sum_{i=1}^{k} \frac{2^{rel_i} - 1}{\log_2(i+1)}$$
$$NDCG_k = \frac{DCG_k}{IDCG_k}$$

**MRR (Mean Reciprocal Rank):**
$$MRR = \frac{1}{|Q|} \sum_{q=1}^{|Q|} \frac{1}{rank_q}$$

## 55c. Онлайн метрики

**Как измеряются:** A/B тесты на реальных пользователях.

**Metric tree:** иерархия метрик от бизнес-целей до proxy-метрик.

**North star metric:** главная метрика продукта.

## 55d. RankNet loss

**Предсказывает:** вероятность того, что документ i релевантнее документа j.

$$P_{ij} = \sigma(s_i - s_j)$$
$$L = -\sum_{i,j} \bar{P}_{ij} \log P_{ij} + (1 - \bar{P}_{ij}) \log(1 - P_{ij})$$

**Другие функции потерь:** LambdaRank, ListNet, ListMLE.

# Теоретический минимум — Краткие ответы

1. **Регрессия и классификация:** Регрессия — предсказание непрерывной величины; Классификация — предсказание дискретного класса.

2. **Unsupervised learning:** Обучение без меток. Примеры: кластеризация (K-means), снижение размерности (PCA).

3. **i.i.d.:** Независимые одинаково распределённые данные. Используется в MLE для факторизации совместной вероятности.

4. **Наивный Байес:** P(y|x) ∝ P(y)∏P(xⱼ|y). Наивность — в предположении условной независимости признаков.

5. **Линейная регрессия MSE:** L = ||Xw - y||², ∂L/∂w = 2Xᵀ(Xw - y)

6. **Градиентный спуск:** wₜ₊₁ = wₜ - η∇L. Для больших данных: SGD (мини-батчи).

7. **Likelihood и MLE:** L(θ) = P(Data|θ). MLE используется для оценки параметров распределений.

8. **Cross-validation:** Многократное разбиение данных. Больше folds → меньше variance оценки, но дороже.

9. **Overfitting/Underfitting:** Overfitting: train ≪ test. Underfitting: train ≈ test (оба плохие).

10. **Параметры vs гиперпараметры:** Параметры учатся (веса). Гиперпараметры задаются (λ, глубина).

11. **Регуляризация:** Штраф за сложность. L1 — разреженность, L2 — уменьшение весов.

12. **L2 и bias:** Bias обычно не регуляризируют — он не влияет на сложность модели.

13. **Нормализация данных:** При разном масштабе признаков градиенты несбалансированы.

14. **Линейная классификация:** ŷ = sign(wᵀx + b). Margin = y(wᵀx + b).

15. **Precision/Recall:** Precision = TP/(TP+FP), Recall = TP/(TP+FN).

16. **Несбалансированные данные:** Balanced accuracy, weighted F1, class weights, oversampling.

17. **ROC AUC:** Площадь под кривой TPR vs FPR. Строится варьированием порога.

18. **Logistic loss:** -∑[y log p + (1-y) log(1-p)]. Это NLL для Bernoulli.

19. **SVM:** Максимизация margin. min ||w||² при yᵢ(wᵀxᵢ + b) ≥ 1.

20. **Жадный алгоритм дерева:** На каждом узле выбираем лучшее разбиение по критерию (Gini, Entropy).

21. **Нулевая ошибка дерева:** Дерево может разбить до листов с одним объектом.

22. **Метка в листе (классификация):** Большинство голосов или вероятности.

23. **Метка в листе (регрессия):** Среднее значений. Не зависит от критерия.

24. **Bagging:** Bootstrap + обучение моделей + усреднение.

25. **Random Forest:** Bagging + случайное подмножество признаков на каждом разбиении.

26. **Gradient Boosting:** Следующая модель обучается на антиградиент loss.

27. **Backpropagation:** Chain rule: ∂L/∂w = ∂L/∂y × ∂y/∂w. Вектор на вектор: якобиан.

28. **Conv layer:** Применение ядра к локальным областям. (I * K)ᵢⱼ = ∑ I × K.

29. **Почему CNN лучше FC для изображений:** Меньше параметров, инвариантность к сдвигу, иерархия признаков.

30. **Vanilla RNN:** hₜ = tanh(Wₓₕxₜ + Wₕₕhₜ₋₁ + b).

31. **Dropout:** Случайное обнуление нейронов с вероятностью p во время обучения.

32. **Dropout и BatchNorm на inference:** Dropout выключается; BatchNorm использует running statistics.

33. **PCA:** Найти ортонормированный базис, максимизирующий дисперсию проекций (или минимизирующий ошибку восстановления).

## 2. Метод максимального правдоподобия: формулировка, использование свойства i.i.d. и переход к логарифму

**Формулировка:** найти параметры θ, максимизирующие вероятность наблюдать данные:
$$\theta^* = \arg\max_\theta L(\theta) = \arg\max_\theta P(X|\theta)$$

**Использование i.i.d.:** при независимых одинаково распределённых данных:
$$L(\theta) = P(x_1, ..., x_n | \theta) = \prod_{i=1}^{n} P(x_i | \theta)$$

**Переход к логарифму:**
$$\log L(\theta) = \sum_{i=1}^{n} \log P(x_i | \theta)$$

Преимущества: произведение → сумма (удобнее дифференцировать), избегаем numerical underflow.

---

## 3. Постановка задачи регрессии. Что добавляется в случае линейной регрессии?

**Задача регрессии:** по признакам X предсказать непрерывную целевую переменную y.
$$f: X \to \mathbb{R}$$

**Линейная регрессия добавляет:**
- Модель линейна по параметрам: $\hat{y} = w^T x + b$
- Функция потерь (обычно MSE): $L = \frac{1}{n}\sum(y_i - \hat{y}_i)^2$
- Предположения: линейность связи, гомоскедастичность, независимость ошибок

---

## 4. В чём состоит наивность наивного байесовского классификатора?

**Наивное предположение:** признаки условно независимы при фиксированном классе:
$$P(x_1, x_2, ..., x_d | y) = \prod_{j=1}^{d} P(x_j | y)$$

Это "наивно", потому что в реальности признаки часто коррелируют. Например, в тексте слова "машинное" и "обучение" часто встречаются вместе, но наивный Байес считает их независимыми.

---

## 5. Выписать аналитическое решение задачи линейной регрессии. Какие могут быть проблемы при его использовании?

**Аналитическое решение (Normal Equation):**
$$w^* = (X^T X)^{-1} X^T y$$

**Проблемы:**
1. **Вычислительная сложность:** O(d³) для обращения матрицы — медленно при d > 10000
2. **Память:** нужно хранить X^T X размера d×d
3. **Вырожденность:** если X^T X вырождена (мультиколлинеарность), обратной матрицы не существует
4. **Численная нестабильность:** при плохой обусловленности результат неточен

---

## 6. Теорема Гаусса-Маркова: формулировка

**Формулировка:** При выполнении условий:
1. Линейность: y = Xw + ε
2. E[ε] = 0 (ошибки с нулевым средним)
3. Var(ε) = σ²I (гомоскедастичность, некоррелированность)
4. X — детерминированная матрица полного ранга

OLS-оценка $\hat{w} = (X^T X)^{-1} X^T y$ является **BLUE** (Best Linear Unbiased Estimator) — имеет минимальную дисперсию среди всех линейных несмещённых оценок.

## 7. Регуляризация: перечислить известные типы, для чего нужна и как изменится аналитическое решение?

**Типы регуляризации:**
- **L2 (Ridge):** $\lambda ||w||^2$
- **L1 (Lasso):** $\lambda \sum |w_j|$
- **Elastic Net:** $\lambda_1 \sum |w_j| + \lambda_2 ||w||^2$
- **Dropout** (для нейросетей)

**Для чего нужна:**
- Борьба с переобучением
- Уменьшение дисперсии модели
- Решение проблемы мультиколлинеарности

**Аналитическое решение с L2:**
$$w^* = (X^T X + \lambda I)^{-1} X^T y$$

## 8. Запишите функции потерь в задаче регрессии (3-5 шт)

1. **MSE (Mean Squared Error):** $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$
2. **MAE (Mean Absolute Error):** $\frac{1}{n}\sum|y_i - \hat{y}_i|$
3. **RMSE (Root MSE):** $\sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}$
4. **Huber Loss:** квадратичная при малых ошибках, линейная при больших
5. **MAPE:** $\frac{100\%}{n}\sum\frac{|y_i - \hat{y}_i|}{|y_i|}$

## 9. Что такое переобучение и как его можно обнаружить?

**Переобучение (Overfitting):** модель слишком хорошо подстроилась под обучающие данные, запомнила шум, и плохо обобщает на новые данные.

**Как обнаружить:**
- Низкая ошибка на train, высокая на validation/test (большой gap)
- Learning curves: train error падает, validation error растёт или не падает
- Модель даёт нестабильные предсказания при небольших изменениях данных

## 11. Техники валидации модели: перечислить 3-5 известных способов

2. **K-Fold Cross-Validation:** K разбиений, каждый fold по очереди для валидации
3. **Stratified K-Fold:** K-Fold с сохранением пропорций классов

## 12. kNN-алгоритм: к чему может привести разный масштаб признаков, что делать?

**Проблема:** если признаки в разных масштабах (например, возраст 0-100 и доход 0-1000000), признак с большим масштабом будет доминировать в расстоянии.

**Что делать:**
- **StandardScaler:** (x - mean) / std — стандартизация
- **MinMaxScaler:** (x - min) / (max - min) — нормализация в [0, 1]
- **RobustScaler:** устойчив к выбросам

**Важно:** fit scaler только на train, transform на train и test.

## 13. Может ли так случиться, что при добавлении новой фичи метрики валидации падают? Почему?

**Да, может.** Причины:

1. **Шумный признак:** не несёт полезной информации, но добавляет variance
2. **Переобучение:** больше признаков → больше параметров → легче переобучиться
3. **Проклятие размерности:** в высоких измерениях данные становятся разреженными
4. **Мультиколлинеарность:** новый признак коррелирует с существующими
5. **Data leakage:** признак содержит информацию из будущего/target

## 14. Что предсказывает логистическая регрессия?

Логистическая регрессия предсказывает **вероятность принадлежности к положительному классу:**
$$P(y=1|x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}}$$

Выход — число от 0 до 1, интерпретируемое как вероятность. Для получения класса применяется порог (обычно 0.5).

---

## 15. Формула сигмоиды

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**Свойства:**
- Область значений: (0, 1)
- σ(0) = 0.5
- σ(-z) = 1 - σ(z)
- Производная: σ'(z) = σ(z)(1 - σ(z))

## 16. Назовите стратегии агрегации бинарных предсказаний в мультиклассовое. Количество моделей?

**One-vs-All (One-vs-Rest):**
- Количество моделей: **K** (по числу классов)
- Каждая модель: класс i vs все остальные
- Предсказание: класс с максимальным score

**One-vs-One:**
- Количество моделей: **K(K-1)/2** (все пары классов)
- Каждая модель: класс i vs класс j
- Предсказание: голосование

## 17. Что должна предсказывать модель, чтобы мы могли подсчитать ROC-AUC?

Модель должна предсказывать **score (оценку уверенности)** или **вероятность** принадлежности к положительному классу, а не просто бинарную метку.

Это может быть:
- Вероятность P(y=1|x) из логистической регрессии
- Расстояние до гиперплоскости в SVM
- Любое монотонное преобразование вероятности

## 18. Значение (семантика) метрик классификации: Precision, Recall

**Precision (Точность):** из всех объектов, которые модель назвала положительными, какая доля действительно положительные?
$$Precision = \frac{TP}{TP + FP}$$

**Recall (Полнота):** из всех реально положительных объектов, какую долю модель нашла?
$$Recall = \frac{TP}{TP + FN}$$

**Пример:** поиск больных
- Precision: какая доля "диагностированных" действительно больны
- Recall: какую долю всех больных мы нашли

## 19. Какой размер имеет бутстрапированная выборка?

Бутстрапированная выборка имеет **тот же размер n**, что и исходная выборка.

Выборка формируется случайным выбором n объектов **с возвращением** из исходных n объектов.

В среднем ~63.2% уникальных объектов попадают в каждую bootstrap выборку (остальные ~36.8% — out-of-bag).

## 20. Чем Random Forest отличается от Bagging над деревьями решений?

**Bagging над деревьями:**
- Bootstrap выборки
- На каждой выборке обучается полное дерево
- Усреднение предсказаний

**Random Forest добавляет:**
- **Random Subspace Method:** на каждом разбиении в узле выбирается случайное подмножество признаков (обычно √d для классификации, d/3 для регрессии)
- Это дополнительно декоррелирует деревья
- Уменьшает variance сильнее, чем просто bagging

## 21. Что является таргетом для следующего дерева в бустинге в общем случае?

В общем случае таргетом является **антиградиент (отрицательный градиент) функции потерь** по предсказаниям:
$$r_i = -\frac{\partial L(y_i, f(x_i))}{\partial f(x_i)}$$

Следующее дерево обучается аппроксимировать этот антиградиент.

---

## 22. Что является таргетом для следующего дерева в бустинге в случае MSE?

Для MSE loss $L = \frac{1}{2}(y - f(x))^2$:

$$r_i = -\frac{\partial L}{\partial f(x_i)} = y_i - f(x_i)$$

Таргетом являются **остатки (residuals)** — разность между истинными значениями и текущими предсказаниями.

## 33. Напишите формулу для вычисления momentum (инерции) в градиентном спуске

**Momentum SGD:**
$$v_t = \gamma v_{t-1} + \eta \nabla L(w_t)$$
$$w_{t+1} = w_t - v_t$$

где:
- γ — коэффициент momentum (обычно 0.9)
- η — learning rate
- v — накопленная скорость

Momentum сглаживает обновления и помогает преодолевать локальные минимумы.

## 34. Чем являются новые признаки в алгоритме PCA?

Новые признаки — это **линейные комбинации исходных признаков**, соответствующие направлениям максимальной дисперсии данных.

$$z_k = \sum_{j=1}^{d} v_{kj} x_j = v_k^T x$$

где $v_k$ — k-я главная компонента (собственный вектор ковариационной матрицы).

Новые признаки:
- Ортогональны друг другу
- Упорядочены по убыванию дисперсии
- Некоррелированы

## 35. Сформулируйте алгоритм PCA через максимизацию/минимизацию дисперсии по осям

**Формулировка через максимизацию дисперсии:**

Найти направление $v_1$, максимизирующее дисперсию проекции:
$$v_1 = \arg\max_{||v||=1} Var(Xv) = \arg\max_{||v||=1} v^T \Sigma v$$

Затем найти $v_2 \perp v_1$, максимизирующее оставшуюся дисперсию, и т.д.

**Эквивалентная формулировка через минимизацию ошибки восстановления:**

Найти k-мерное подпространство, минимизирующее:
$$\sum_i ||x_i - \hat{x}_i||^2$$

где $\hat{x}_i$ — проекция на подпространство.

## 36. Изложите геометрическую интерпретацию SVM

**Геометрическая интерпретация:**

SVM ищет **гиперплоскость**, которая:
1. Разделяет классы (точки разных классов по разные стороны)
2. Максимизирует **отступ (margin)** — расстояние до ближайших точек каждого класса

**Опорные векторы** — точки, лежащие на границе margin (ближайшие к гиперплоскости). Только они определяют положение гиперплоскости.

**Margin = 2/||w||**, поэтому максимизация margin эквивалентна минимизации ||w||².

## 37. Какая функция потерь соответствует алгоритму SVM?

**Hinge Loss:**
$$L = \max(0, 1 - y_i(w^T x_i + b))$$

где $y_i \in \{-1, +1\}$

**Свойства:**
- Равен 0, если объект классифицирован правильно с margin ≥ 1
- Линейно растёт при уменьшении margin ниже 1
- Не штрафует объекты с большим положительным margin

## 38. Запишите формулу информационной энтропии

$$H(p) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

где $p_k$ — вероятность k-го класса.

**Свойства:**
- H ≥ 0
- H = 0, когда один класс имеет вероятность 1 (полная определённость)
- H максимальна при равномерном распределении
- Для бинарного случая: H(p) = -p log₂ p - (1-p) log₂(1-p)

## 39. Запишите функцию, оптимизируемую при поиске разделяющего правила в вершине дерева

**Information Gain (для энтропии):**
$$IG = H(parent) - \sum_{child} \frac{n_{child}}{n_{parent}} H(child)$$

Максимизируем IG (или минимизируем взвешенную энтропию детей).

**Для Gini:**
$$\Delta Gini = Gini(parent) - \sum_{child} \frac{n_{child}}{n_{parent}} Gini(child)$$

где $Gini(p) = 1 - \sum_k p_k^2$

## 40. Какие функции активации используются в рекуррентных нейросетях? Почему именно они?

**Основные функции:**
- **tanh** — для вычисления hidden state
- **sigmoid (σ)** — для гейтов в LSTM/GRU

**Почему tanh:**
- Выход в [-1, 1] — центрирован около 0
- Ограниченные значения предотвращают exploding activations
- Производная ненулевая в широком диапазоне

**Почему sigmoid для гейтов:**
- Выход в [0, 1] — интерпретируется как "степень открытости" гейта
- 0 = полностью закрыт, 1 = полностью открыт
- Позволяет плавно регулировать поток информации

## 43. Что такое padding и stride в свёрточном слое? Зачем они используются?

**Padding:** добавление нулей (или других значений) по краям входа.
- **Зачем:** сохранить пространственный размер выхода, обрабатывать края
- padding='same' → выход такого же размера как вход (при stride=1)

**Stride:** шаг сдвига ядра.
- **Зачем:** уменьшить пространственный размер выхода (downsampling)
- stride=2 → размер уменьшится примерно вдвое

## 44. Зачем нужен pooling слой в нейронных сетях? Каковы его преимущества перед свёрткой?

**Зачем нужен:**
1. Уменьшение пространственного размера (downsampling)
2. Уменьшение числа параметров и вычислений
3. Инвариантность к небольшим сдвигам
4. Увеличение receptive field

**Преимущества перед свёрткой:**
1. **Нет обучаемых параметров** — не может переобучиться
2. Быстрее вычисляется

4. Max pooling выделяет наиболее активные признаки

## 45. С какой основной проблемой сталкивались исследователи, увеличивавшие глубину нейросетей?

**Degradation problem (проблема деградации):**

При увеличении глубины после определённого момента:
- Ошибка на **обучающей выборке** начинала расти
- Это не переобучение (test error тоже рос)
- Более глубокая сеть работала хуже более мелкой

**Причина:** сложность оптимизации — градиенты затухают или взрываются.

**Решение:** Residual connections (ResNet) — y = F(x) + x

**Описание:**
1. **Encoder:** читает входную последовательность, выдаёт финальный hidden state (context vector)
2. **Decoder:** получает context vector как начальное состояние, генерирует выход авторегрессионно

## 48. Какую проблему решает алгоритм beam search?

**Проблема:** жадный поиск (greedy decoding) выбирает на каждом шаге токен с максимальной вероятностью, но это не гарантирует глобально лучшую последовательность.

**Beam search решает:** поддерживает k лучших гипотез (beam width = k) на каждом шаге, что позволяет найти более вероятную последовательность.

**Пример:**
- Greedy: выбрали "I" → "am" → застряли
- Beam search (k=3): рассматриваем несколько вариантов, можем найти лучший путь

## 49. Какая метрика является основной в задаче машинного перевода? Из каких двух частей она состоит?

**BLEU (Bilingual Evaluation Understudy)**

**Две части:**

1. **Precision по n-граммам:**
   $$p_n = \frac{\text{число совпавших n-грамм}}{\text{общее число n-грамм в гипотезе}}$$
   Усредняется для n = 1, 2, 3, 4

2. **Brevity Penalty (BP):**
   $$BP = \begin{cases} 1 & \text{if } c > r \\ e^{1-r/c} & \text{if } c \leq r \end{cases}$$
   где c — длина гипотезы, r — длина референса
   Штрафует слишком короткие переводы

**Итоговая формула:**
$$BLEU = BP \cdot \exp\left(\sum_{n=1}^{4} w_n \log p_n\right)$$

## 50. Чему равен attention score в seq2seq?

**Attention score** измеряет релевантность каждого состояния энкодера для текущего шага декодера.

**Формулы (разные варианты):**

**Dot-product (Luong):**
$$score(h_t^{dec}, h_s^{enc}) = (h_t^{dec})^T h_s^{enc}$$

**Additive (Bahdanau):**
$$score(h_t^{dec}, h_s^{enc}) = v^T \tanh(W_1 h_t^{dec} + W_2 h_s^{enc})$$

**Scaled dot-product (Transformer):**
$$score(Q, K) = \frac{QK^T}{\sqrt{d_k}}$$

После вычисления scores применяется softmax для получения весов внимания.
